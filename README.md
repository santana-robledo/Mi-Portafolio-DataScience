Repositorio que documenta mi trayectoria de aprendizaje y desarrollo de habilidades en Ciencia de Datos, Análisis Estadístico y Aprendizaje Automático. Contiene ejercicios, prácticas académicas y proyectos aplicados que abarcan desde los fundamentos de Python y SQL hasta el desarrollo de modelos predictivos y el análisis de series temporales.

Mi objetivo es construir una base sólida para transformar datos en información útil, identificar patrones, generar predicciones y apoyar la toma de decisiones mediante herramientas estadísticas y computacionales.

## Objetivo del repositorio

Documentar mi aprendizaje práctico en ciencia de datos, mostrando cómo aplico conceptos de programación, estadística y aprendizaje automático para explorar información, comprender problemas y desarrollar soluciones basadas en datos.

El repositorio también funciona como portafolio técnico para demostrar mi progreso, las herramientas que utilizo y los conocimientos que continúo desarrollando.

## Contenido del repositorio

### Fundamentos de Python

Ejercicios para desarrollar habilidades de programación y preparar datos para su análisis.

Variables, estructuras de control y ciclos (for, while).

Programación orientada a objetos.

Manejo de registros y estructuras de datos.

Manipulación de datos con Pandas y NumPy.

### Análisis exploratorio de datos (EDA)

Exploración de conjuntos de datos para comprender su estructura, detectar patrones e identificar posibles problemas de calidad.

Estadística descriptiva.

Limpieza y transformación de datos.

Detección de valores atípicos.

Análisis de distribuciones y relaciones entre variables.

Visualización de datos con Matplotlib y Seaborn.

### Estadística y análisis inferencial

Aplicación de herramientas estadísticas para analizar datos, evaluar hipótesis e interpretar resultados.

Pruebas de hipótesis.

Correlación y regresión.

Regresión lineal simple y múltiple.

Intervalos de confianza y predicción.

Evaluación de modelos mediante R², RMSE y otras métricas.

### Machine Learning supervisado

Modelos que aprenden relaciones a partir de datos conocidos para realizar predicciones o clasificaciones.

Regresión lineal y regresión logística.

K-Nearest Neighbors (KNN).

Máquinas de soporte vectorial (SVM).

Árboles de decisión y bosques aleatorios.

Evaluación y comparación de modelos predictivos.

### Machine Learning no supervisado

Técnicas para descubrir estructuras y grupos dentro de los datos sin depender de etiquetas previamente definidas.

K-Means y clustering jerárquico.

Reducción de dimensionalidad con PCA.

Descomposición en valores singulares (SVD).

Segmentación de clientes mediante RFM.

Análisis de patrones de compra con Market Basket Analysis.

### Bases de datos y SQL

Consultas y operaciones para recuperar, relacionar y analizar información almacenada en bases de datos relacionales.

Fundamentos y consultas con SQLite.

Consultas entre tablas y operaciones de unión.

Filtrado, agrupación y agregación de información.

Aplicación de SQL al análisis de datos.

### Series temporales y pronóstico

Análisis de datos registrados a lo largo del tiempo para identificar comportamientos históricos y desarrollar pronósticos.

Exploración y visualización de series temporales.

Autocorrelación y análisis de rezagos.

Modelos autorregresivos AR(p).

Modelos ARIMA y técnicas de pronóstico.

Evaluación de predicciones mediante métricas de error.

##  Proyectos de interés

Entre los trabajos documentados y las áreas de aplicación de este repositorio destacan:

Segmentación de clientes: aplicación de métricas RFM y técnicas de clustering para identificar grupos de clientes según su comportamiento de compra.

Modelos predictivos: aplicación de regresión para estudiar relaciones entre variables y estimar valores.

Análisis de series temporales: exploración de datos históricos y desarrollo de modelos de pronóstico.

Análisis de datos empresariales: utilización de Python y SQL para transformar datos en información útil para la toma de decisiones.

Consulta los notebooks correspondientes para conocer el desarrollo de cada ejercicio o proyecto. Los resultados y conclusiones específicos se documentan dentro de cada análisis.
